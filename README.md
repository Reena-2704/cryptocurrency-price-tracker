# Cryptocurrency Price Tracker 💰📊

A Python-based Cryptocurrency Price Tracker that collects
cryptocurrency prices and market data using Selenium.

## Features

- Real-time cryptocurrency price tracking
- Top 10 cryptocurrency data
- 24-hour price change
- Market capitalization
- Historical price tracking
- CSV export
- Price filtering
- Interactive dashboard

## Technologies Used

- Python
- Selenium
- Pandas
- Streamlit
- Chrome WebDriver
- CSV

## Project Output

The dashboard displays cryptocurrency prices, market changes,
market capitalization and historical trends.

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
streamlit run crypto_price_tracker.py
